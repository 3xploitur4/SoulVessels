## Context

**Design**: addendum §"Production milestones" M0 ("confirm an empty project exports an APK");
bible §1 (Android ARM64). `SETUP.md` (JDK 17, SDK path with a space, export templates).
**Decision**: D-007.

## Acceptance Criteria

- [ ] `export_presets.cfg` has preset "Android" (debug, runnable): arm64-v8a only, package `com.soulvessels.chapter1`, landscape, min SDK 24, target SDK 35, Mobile renderer kept, ETC2/ASTC.
- [ ] A debug keystore exists under `engine/godot/editor_data/keystores/` (generated by the bundled JDK's keytool) and the editor settings name it.
- [ ] `bash tools/build/export_android.sh` runs the import then `--headless --export-debug "Android" builds/android/soulvessels-debug.apk` and exits 0; the APK exists and is > 20 MB.
- [ ] `aapt`/`apksigner verify` (build-tools 36) confirms the APK is signed; `unzip -l` shows `lib/arm64-v8a/libgodot_android.so` and no `armeabi-v7a`.
- [ ] `production/qa/smoke-2026-11-13.md` records the export log tail.

## Implementation Notes

Self-contained editor: settings live in `engine/godot/editor_data/editor_settings-4.7.tres`.
The export script sets `JAVA_HOME` to `engine/jdk-17` and calls the console binary.
Gradle build stays off (no plugins yet), so the prebuilt `android_debug.apk` template is used.
