# Play Soul Vessels yourself

Chapter I is playable end to end: four zones, three bosses, Ilyr's awakening and the chapter-end
screen.

## On the PC (quickest)

Double-click one of these in the project folder:

- **`Play Soul Vessels.bat`**: the full game from the title screen, with three save slots.
- **`Test a part of the game.bat`**: pick a number to jump straight to a part. It uses its own
  save folder, so your real saves are never touched.

  | Pick | Where it starts |
  | --- | --- |
  | 1 | A new game from the very start: the wisp, then Caelan |
  | 2 | Zone 2, the Mycelium Forest (Nyra) |
  | 3 | Zone 3, the Sunken Palace (Seris, rune puzzles) |
  | 4 | Just before the Weeping Sovereign (walk right) |
  | 5 | Zone 4, the Sealed Rift (Darius under the rubble in room 3) |
  | 6 | Just before the Guardian Below (walk right) |
  | 7 | Just before the Abyssal Leviathan (walk right) |
  | 8 | Ilyr's awakening and the end of Chapter I |
  | 9 | A Soul Altar room to try the Vessels, upgrades and second weapons |

### Keyboard

| Key | Action |
| --- | --- |
| A / D or arrows | move |
| Space | jump (again in the air: double jump) |
| J | attack (press again to chain the combo) |
| K | dodge |
| U | ability 1 (hold for some Vessels) |
| I | ability 2 |
| O | Ultimate (needs a full Soul Gauge) |
| Q / E | swap to the previous / next Vessel |
| F | drink a Soul Flask (heal) |
| W | interact: rest at an altar, free a Vessel, read, enter |
| Esc | pause menu |
| Tab | map |
| F3 | debug overlay (frame rate and state) |

A gamepad also works: plug it in and press any button; the touch controls hide.

## On an Android phone

1. Copy `builds/android/soulvessels-debug.apk` to the phone (USB cable, Google Drive, or email it
   to yourself).
2. Open it on the phone. Android will ask to allow installs from that app: allow it once.
3. Play with the on-screen controls: left side to move, buttons on the right.

This is a debug build, so Android may warn that it comes from an unknown source. That's expected.
It is the first time it runs on a real phone: please tell me if it feels smooth or stutters.

## What to look at

- **How it feels:** jump and attack timing, dodging, swapping Vessels mid-combo, parrying the gold flashes.
- **How it looks:** the new Vessel, boss and altar art. The monsters and backgrounds are still the old art.
- **Difficulty:** whether the bosses feel fair. They were tuned by numbers, never played by hand.
- **Anything confusing or broken:** tell me what you did and what happened. A screenshot helps.
